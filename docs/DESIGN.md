# 题目、输入与允许操作

## 1. 研究目标

给定平面上一段非零长度的可见弧 $C$。已知它属于某条非退化实圆锥曲线 $S$，且 $S$ 为非圆椭圆、双曲线或抛物线之一。使用无刻度直尺和圆规，通过有限次精确操作判定 $S$ 的类别。

本项目中“椭圆”均指非圆椭圆。圆在通常的圆锥曲线分类中属于非退化椭圆，本题按输入约定排除圆。

输出为以下三个标签之一。

| 输出 | 意义 |
|---|---|
| 椭圆 | 所属曲线为非圆椭圆 |
| 抛物线 | 所属曲线为抛物线 |
| 双曲线 | 所属曲线为双曲线 |

研究交付包括完整题面、有限判定流程、正确性与覆盖证明、SageMath 精确核验及 Manim 动画。步数最小化研究暂缓。

## 2. 可见弧的含义

$C$ 是 $S$ 上一段连通的真实弧，含有无穷多个不同点。允许任意短弧、长弧、包含顶点的弧、具有对称性的弧。双曲线的连通弧位于同一个分支上。

弧的端点可以未标记。初始信息仅有可见弧及曲线类别的承诺。坐标系、单位长度、焦点、准线、中心、对称轴和顶点标记由具体作法按需要构造。

这里的精确弧是理想几何输入。照片、像素轮廓、带噪点云的拟合与统计分类属于另一种输入模型。

## 3. 本版采用的取点模型

允许在可见弧上选取辅助点。本算法选取五个互不相同的点，记为 $A,B,C_0,D,E$。下标用于区分第三个点 $C_0$ 与整段可见弧 $C$。

这项取点能力是明确的输入规则。本版选择它的依据是原始问答本身使用弧上取点，题目又没有预先标记点。每次选取只要求与已选点不同。可见弧有无穷多个点，因此固定五次选取即可完成，且任意合法选择都满足后续证明。

点名与弧上先后次序独立。算法无需给点排序，也无需检验选出的弦是否处于一般位置。非退化圆锥曲线上任意三个不同点不共线，这个性质自动保证标架和插值的合法性。

如果另行采用禁止在弧上选点、仅允许从有限已标记点出发的模型，需要重新规定初态。本版定理对应本节定义的模型。

## 4. 作图与判定操作

允许的基础几何操作如下。

1. 通过两个已有不同点画完整直线。
2. 以已有点为圆心，经过另一个已有点画圆。采用与前四个项目一致的塌圆规语义。
3. 获得已有直线、圆之间的确定有限实交点。
4. 根据已有点线关系进行精确的相等、共线和直线上的次序判定。
5. 按第 3 节规则选取弧上的五个不同点。

中点、垂线、平行线、长度转移以及有向长度四则运算采用经典尺规构造。答案将用于本题的相似三角形算术展开在 [CONSTRUCTION.md](CONSTRUCTION.md) 中。

本算法取点后只使用直线、圆和已有点。曲线方程的系数由五点信息推导。程序中的坐标表达负责核验这套几何操作。

最终的符号判断通过一个已有定向直线上的点完成。该点与原点重合时输出抛物线，位于正射线上时输出双曲线，位于负射线上时输出椭圆。这里使用精确的相等和次序关系。

## 5. 临时自建标架

以 $A$ 为原点，以 $\overrightarrow{AB}$ 和 $\overrightarrow{AC_0}$ 为基向量。它们线性无关，形成一个仿射标架。

任一点 $P$ 在该标架中唯一表示为

$$P=A+x\overrightarrow{AB}+y\overrightarrow{AC_0}.$$

两个基向量可以不垂直，长度也可以不同。$AB$ 同时作为有向长度算术的单位。坐标数由平行投影和相似三角形构造获得。

这是从题面给定信息出发的辅助作图。最终分类对这个标架的选择保持不变。

## 6. 连续几何定理与可执行核验的范围

证明覆盖任意实坐标的合法弧，包括选点坐标为超越数的情形。它依赖有序实数域上的恒等式、有限次非零除法和曲线的非退化性。

SageMath 案例执行层使用 $\mathbb Q$ 和实代数数域 `AA`。符号多项式检查覆盖一般参数关系，具体案例提供独立的精确重放。对任意实输入的覆盖性由 [PROOF.md](PROOF.md) 给出。
