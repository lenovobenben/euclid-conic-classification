# 题目、输入与允许操作

## 1. 研究目标

给定一段非零长度的可见弧 $C$，已知它属于某条非退化实圆锥曲线 $S$，且 $S$ 为非圆椭圆、抛物线或双曲线之一。用无刻度直尺和圆规，经过有限作图判定 $S$ 的类别。

本项目中的“椭圆”均指非圆椭圆。圆按题面约定排除。输出为曲线类别。

交付包括详细题面、几何作图答案、一般证明、SageMath 精确核验与 Manim 动画。最小步数研究暂缓。

## 2. 可见弧

可见弧为曲线上的一段连通真实弧。允许任意短弧、长弧、含顶点弧和对称弧。双曲线的连通弧位于同一分支。

弧端点可以未标记。初始信息为可见弧及曲线类别的承诺。题面使用理想精确几何对象。

## 3. 取点与可见弧求交

允许沿可见弧依次选取四个不同点 $A,B,C,D$。间距任意，也可反向取点，只需保持沿弧的一致次序。

如果可见部分包含整条闭合椭圆，可以先选择其中一段按顺序包含四点的真子弧。初始四点无需包含输入弧的端点。

允许直线与可见弧求交。主解只调用两次，每次所需的两个交点均由一般存在性证明保证落在可见范围内。第五个用于作切线的点直接复用其中一个交点。

## 4. 尺规基础操作

1. 通过两个已有不同点画完整直线。
2. 以已有点为圆心，经过另一个已有点画圆，采用系列的塌圆规语义。
3. 获得已有直线、圆之间的确定有限实交点。
4. 按上一节选取弧上点，并取得指定直线与可见弧的交点。
5. 根据已有对象精确判断平行、相交、相等、共线、介于两点之间与同侧关系。

中点、垂线和平行线使用经典尺规构造。五点切线分支表展开为连线、求交和过点作平行线，详见 [CONSTRUCTION.md](CONSTRUCTION.md)。

同侧关系还可通过连接两点，再检查该线与被比较直线的交点是否位于线段内来实现。连线平行于被比较直线时，两点处于同侧。

## 5. 执行与原理的分工

实际作图依次得到两组平行弦、两条直径、可能存在的中心与一条切线。执行者通过画线和取点获得这些对象，再观察几何位置关系。

证明中使用坐标与方程解释直径、切线及侧别性质。SageMath 使用精确坐标重放作图，独立检查各条线和各个交点。五点插值判别式保留为另一套核验依据，见 [ALGEBRA.md](ALGEBRA.md)。

## 6. 通解标准

主解必须对全部合法弧及全部按次序选出的四点成立。所有中间步骤均应有定义，所有平行与重合情形须给出有限分支或证明排除。

主定理覆盖任意实坐标输入。SageMath 案例执行使用有理数与实代数数域 `AA`，一般符号恒等式及完整数学证明负责更广的参数范围。具体证据层次见 [VERIFICATION.md](VERIFICATION.md)。

## 7. 动画范围

Manim 开头用一页简述原理，此后按顺序展示实际作图与最终分类。中点和平行线采用通常尺规宏，允许省略部分标准辅助圆。详细原理和分支证明集中在专门文档中。
