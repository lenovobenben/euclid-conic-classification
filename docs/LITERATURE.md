# 来源、原始思路与本项目定位

## 1. 题目来源

直接题源是 `lenovobenben/ai-math-notes` 中的“圆锥曲线作图判定”，对话 ID 为 `695490a2-9cc4-8321-93f3-c741a7f628ed`。

本次读取的本地版本与 GitHub `main` 一致，提交为 `50cccad292a296087770a377080dcde9ef40657b`。原始问答按原样保存在 [sources/original_conic_qa.md](../sources/original_conic_qa.md)。[题集仓库](https://github.com/lenovobenben/ai-math-notes)

原题要求可见弧不对称、且不含曲线顶点。本项目按照用户确认后的题面，覆盖任意位置的非零长度弧，包含对称弧和含顶点弧，并排除圆。

## 2. 原始个人思路

原问答中，用户提出两组不同方向的平行弦。对弦求中点，连接同组中点构造直径，再根据两条直径平行或相交，区分抛物线与中心型圆锥曲线。

用户随后指出原回答的中心线求交与中心对称点测试依赖可见弧之外的信息，提出通过三点夹角与中心位置区分椭圆和双曲线。

这些思路及其提出者保持来源记录。原始回答中的措辞、证明和后续纠错保留在历史快照中。

平行弦中点与直径的经典理论可以作为继续研究该路线的依据。[直径与平行弦理论说明](https://www.maths.gla.ac.uk/wws/cabripages/klein/central.html)

## 3. 原回答中需要订正的部分

“延长很远仍未看到交点”属于近似观察，需要用精确的平行判据替换。反复尝试方向直到找到可见弧上的两个中心对称点，也需要存在性和有限终止证明。

最后一份回答将三点夹角判据表述为适用于椭圆上任意依次选取的三点。这个推广缺少弧长和选点位置的约束。其圆上的论证把点的排列当作被截弧必为大弧的保证，又由 $\gamma-\alpha<2\pi$ 推出内接角大于 $90^\circ$，这些推断需要附加条件。

一个说明长弧问题的非圆椭圆反例为

$$\frac{x^2}{4}+y^2=1,$$

$$X=(2,0),\quad Y=(0,1),\quad Z=(6/5,-4/5),\quad O=(0,0).$$

可沿椭圆的一段长弧按 $X,Y,Z$ 排序。由 $Y$ 出发，两条射线方向分别为 $(2,-1)$ 和 $(6/5,-9/5)$。它们张成的小于 $180^\circ$ 的角内部，其方向的第一分量严格为正。$\overrightarrow{YO}=(0,-1)$ 的第一分量为零，所以中心在角外，而曲线仍然是椭圆。

这一反例说明任意长弧版本需要重新规定选点规则。原题受限弧版本的充分条件可以继续单独研究。

## 4. 本版采用的几何主解

主解沿用用户提出的平行弦中点与直径思路。通过固定的中点引导取得两组方向不同的平行弦，补齐可见交点存在性与有限性证明。中心型曲线使用五点切线构造，再比较中心与另一个弧上点相对于切线的同侧、异侧关系。

切线构造基于退化帕斯卡定理，所有平行情况均翻译为有限平面中的平行线作法。切线侧别判据适用于任意长短的可见弧。

本项目的工作集中在完整的题目和操作模型、全输入域的有限流程、逐层证明、对特殊位置的覆盖、独立 SageMath 精确核验，以及从已验证案例生成的 Manim 演示。

原有五点插值与判别式计算保留在 [ALGEBRA.md](ALGEBRA.md) 中，作为原理与独立核验依据。主答案及动画按几何作图组织。所用直径、帕斯卡和圆锥曲线分类均为经典理论，本版记录具体有限程序及覆盖证明，历史首创性另需专门文献工作。
