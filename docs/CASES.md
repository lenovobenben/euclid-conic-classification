# 通解的特殊情形与分支覆盖

## 1. 主流程的全部分支

| 阶段 | 情形 | 处理 |
|---|---|---|
| 初始取点 | 任意四个按弧顺序排列的不同点 | 均可使用 |
| 平行弦 | 两次所作直线与可见弧求交 | 每次恰有两个可见交点 |
| 直径 | 两条直径平行 | 输出抛物线 |
| 直径 | 两条直径相交 | 取得中心并作切线 |
| 切线构造 | 两个辅助交点均有限 | 连接两点，继续求交 |
| 切线构造 | 只有第一个辅助交点不存在于有限平面 | 过第二点作对应平行线 |
| 切线构造 | 只有第二个辅助交点不存在于有限平面 | 过第一点作对应平行线 |
| 切线构造 | 两对辅助线都平行 | 过切点作指定方向的平行线 |
| 最后切线步骤 | 帕斯卡辅助线平行于第三条对边 | 过切点作第三条对边的平行线 |
| 最终判断 | 中心与另一个弧上点在切线同侧 | 输出椭圆 |
| 最终判断 | 二者在切线异侧 | 输出双曲线 |

全部切线分支见 [CONSTRUCTION.md](CONSTRUCTION.md)。一般覆盖证明见 [PROOF.md](PROOF.md)。

## 2. 长弧、短弧与对称性

两次取平行弦使用固定的中点引导。介值定理保证交点落在已选四点之间的可见子弧中。弧长、是否跨越顶点及是否对称都不改变这一结论。

参数间距为 $10^{-12}$ 的极短弧、包含顶点的对称弧、椭圆长弧、双曲线左右分支、接近渐近线的弧以及仿射变换后的输入均有精确案例。

## 3. 中间点重合

第二组平行弦的引导点 $K_2$ 本来就是第一条弦 $AC$ 的中点 $M_1$，直接复用即可。

中心型曲线中，某条原弦可能经过中心，此时该弦中点即中心。其平行辅助弦在另一条直线上，故第二个中点不同，直径仍然有定义。

两组弦的交点有可能彼此复用，允许给同一点绑定多个几何角色。每个切线构造使用的五个点为 $A,B,C,U,D$，它们的互异性有独立证明。

## 4. 无需执行的退化情况

下列情形由题面和一般证明排除。

- 初始三个不同点共线。
- 同一组两条平行弦的中点重合。
- 两条已构造直径重合。
- 切线构造的两条有限辅助线重合。
- 中心或另一个弧上点落在已作切线上。

每项排除条件的推导见 [PROOF.md](PROOF.md)，对应程序使用精确等式核验。

## 5. 极接近抛物线的情形

保留精确曲线族

$$x^2+\varepsilon y^2-y=0,\qquad \varepsilon=\pm10^{-30}.$$

正参数为椭圆，负参数为双曲线，零参数为抛物线。两条直径在前两种情况下可能十分接近平行，但其精确关系仍为相交。SageMath 的相交与平行判定保持精确。

## 6. 案例核验与全域定理

16 类输入分别选取五个已知弧上点，穷举其中按弧次序排列的四点及其反向次序，共 160 次几何主流程重放。

切线部分在每类输入中枚举四个辅助点的全部 24 种排列，另增加四个精确平行对照，共 388 次检查。一般定理保证所有合法输入的覆盖性，具体案例用于检查代码和分支实现。
