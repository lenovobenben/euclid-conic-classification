# 特殊情形与分支覆盖

## 1. 覆盖原则

主算法的全部选点条件只有五点互异。任意三个选点不共线由曲线的非退化性保证。后续表达式对全部合法输入都具有定义，最终按判别量与零的关系输出。

案例核验使用 $\mathbb Q$ 和 `AA` 精确算术，包含以下情形。

| 情形 | 算法依据 | 精确案例 |
|---|---|---|
| 任意短弧 | 非零弧含无穷多个点，五点唯一性仍成立 | 三类曲线均取间隔 $10^{-12}$ 的参数 |
| 长椭圆弧 | 点名顺序和跨越的象限均不影响插值 | `ellipse_long_arc` |
| 弧包含顶点 | 证明对顶点处的选点同样成立 | 三类 `vertex_symmetric` |
| 对称弧与对称选点 | 两行仍有秩二，叉积非零 | 三类 `vertex_symmetric` |
| 双曲线左支 | 同类曲线的仿射像保持判别量符号 | `hyperbola_left_branch` |
| 双曲线接近渐近线 | 所选点有限且互异即可 | `hyperbola_near_asymptote` |
| 旋转、平移、剪切与反射 | 判别量只乘正平方因子 | `ellipse_reflected_shear`、`hyperbola_rotated_translated`、`parabola_sheared` |
| 根式坐标 | 实代数数域精确计算 | `ellipse_algebraic`、`parabola_algebraic_point` |
| 极接近抛物线的椭圆 | 精确正负判定保留微小差异 | `ellipse_near_parabola` |
| 极接近抛物线的双曲线 | 同上 | `hyperbola_near_parabola` |
| 点名交换 | 任意三个点都能作标架，五点方程唯一 | 每个案例的全部 $5!=120$ 种排列 |

## 2. 极短弧与病态数值

即使五点非常接近，它们仍然精确互异，标架行列式仍然非零。输入越接近共线，浮点误差越容易放大，但精确实数模型中的可构造性保持成立。

`tiny_arc` 案例使用相邻参数相差 $10^{-12}$ 的精确有理数，核验过程中保留所有分子和分母。

对于实际图像或手绘误差，需要另行定义观测精度及容错规则。本项目的定理对应理想尺规输入。

## 3. “几乎等于零”与抛物线

精确的 $\Delta=0$ 才对应抛物线。为了核验这一分支，增加曲线族

$$x^2+\varepsilon y^2-y=0.$$

它的齐次矩阵行列式恒为 $-1/4$，因此对所有参数都非退化。三种情况分别为

$$\varepsilon>0\ \Rightarrow\ \text{椭圆},\qquad
\varepsilon=0\ \Rightarrow\ \text{抛物线},\qquad
\varepsilon<0\ \Rightarrow\ \text{双曲线}.$$

采用有理参数化

$$x=\frac{t}{1+\varepsilon t^2},\qquad
y=\frac{t^2}{1+\varepsilon t^2},$$

取 $t=-2,-1,0,1,2$，并令 $\varepsilon=\pm10^{-30}$。两个精确案例分别输出椭圆和双曲线。$\varepsilon=0$ 由标准抛物线案例覆盖。

## 4. 零值中间量

坐标、差值、最终判别量都允许为零。相应有向长度点与原点重合，算术宏直接复用原点。

相似三角形乘法采用第一坐标差恒为 $1$ 的两点确定方向。加法采用第二坐标差恒为 $1$ 的两点确定方向。它们在任意操作数为零时仍有定义。

如果过已有点所作的平行线恰与已有直线重合，直接复用该直线。相交操作只在两条不同方向的直线之间执行。

## 5. 输入承诺与核验器检查

题目承诺弧属于非退化实圆锥曲线。SageMath 的五点接口检查点数、点的维数、互异性和三个点共线的情况，独立恢复器还检查恢复方程的非退化性。

五点接口只接收五个点，因此它验证的是这些点确定的曲线。整段可见弧属于该曲线的事实来自题面承诺。输入模型中的非圆条件也由题面承诺给出，椭圆案例生成器会核实所用椭圆具有不同半轴。

## 6. 完备性的来源

这份案例表覆盖常见的几何和数值敏感情形。全部合法输入的覆盖性来自五点插值的秩证明、判别量的不变性和三类实二次曲线的分类证明。

因此案例数量、随机成功率与有限枚举的规模分别记录。报告中的 1,920 种排列用于检查程序对标架选择的一致性。
