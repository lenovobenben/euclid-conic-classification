> 经典几何的构造、判定与精确证明
>
> 整理日期：2026-11-10。计划总量：十个项目。前四个已完成，均有本地成果及 GitHub 仓库；后六个的本地项目目录均已建立，依次开展。

## 一、这套系列想做什么

这些题目的作图步骤可能有限，但研究内容可以很丰富：新的构造组织方式、严格的正确性证明、存在性与解数分类，以及覆盖特殊情形的完整程序。

系列的共同目标是把一个清楚、有代表性的几何问题，整理成可以理解、检查和复现的研究成果。步数优化是可选方向；一个完整的判定方法、一份修正原有漏洞的证明，或一个覆盖全部输入的分类，也可以成为项目的主要成果。

后六个项目统一使用 `euclid-` 前缀，以题目命名，不统一加 `-min`。现有四个项目保留原名。

本路线图用于安排后续研究。候选路线、需要证明的命题与已经验证的结论，应在各项目中分别记录。

## 四、第 5 项：圆锥曲线局部弧的类型判定

**建议仓库名：`euclid-conic-classification`**

### 题面

给定一段非零长度的弧 C，已知它属于某条非退化实圆锥曲线 S，且 S 为非圆椭圆、双曲线或抛物线之一。仅用无刻度直尺和圆规，判定 S 属于上述哪一类。本项目中的“椭圆”均指非圆椭圆。

- 弧可长可短。
- 不提供坐标系、焦点、准线、对称轴或顶点标记。
- 不限制弧是否包含顶点，也不限制弧是否恰好对称。
- 已知 S 属于上述圆锥曲线类别，是题目的明确前提。
- 输出是类别，不要求恢复整条曲线、焦点或轴。

没有顶点标记，不意味着弧上没有顶点。算法需要覆盖任意位置的可见弧。

### 为什么值得研究

一小段弧的外观不足以可靠地区分类别，但圆锥曲线这一前提提供了强约束。本题研究怎样通过有限的精确操作，从局部弧中提取确定类型所需的信息。

这是系列中第一个以“判定”作为最终目标的项目。

### 原有思路与首版主解

题集中提出的路线是：

1. 对两组不同方向的平行弦求中点，构造对应直径。
2. 利用直径的关系区分抛物线与中心型圆锥曲线。
3. 对中心型曲线，利用中心相对于可见弧的方位，区分椭圆和双曲线。

平行弦中点与直径的理论有经典依据。后续重点是把取点、取弦和最终方位测试整理成完整程序。

题集中后半段提出了“三点所成夹角与中心位置”的判据。采用该路线时，应明确三点的选取条件；原先依赖无顶点短弧的论证，不能直接覆盖当前允许的任意长弧。可以补齐选点规则，也可以寻找更适合全域证明的替代判据。

当前首版采用五点主解。允许从可见弧选取五个不同点，以前三点自建斜标架，通过平行投影及有向长度算术构造二次项，再构造判别量。任意合法五点均能使用，完整流程和一般证明分别保存在 [ANSWER.md](ANSWER.md) 和 [PROOF.md](PROOF.md)。原始平行弦路线及其来源保存在 [LITERATURE.md](LITERATURE.md)。

### 已固定的首版规则

- 弧的端点可以未标记。
- 允许在可见弧上选取五个互异辅助点，任意合法选择均可使用。
- 取点之后使用已有点、直线和圆完成后续作图。
- 精确相等与直线上的次序关系用于最后的符号判定，完整操作模型见 [DESIGN.md](DESIGN.md)。

这些是输入模型的一部分。证明中可以使用坐标；执行程序时仍以题面给定的信息为准，不能直接读取隐藏的曲线方程或类型。

### 分情况讨论重点

短弧、长弧、含顶点的弧、对称弧，以及选取辅助对象时出现的重合或平行情形。取弦路线应有有限的选取策略，避免依赖没有终止保证的反复尝试。

## 五、第 6 项：借助立方曲线三等分角

**建议仓库名：`euclid-cubic-trisection`**

### 题面

给定坐标系、单位长度及函数曲线 y=x³。另给一个锐角 θ，0<θ<π/2。使用无刻度直尺、圆规以及给定曲线的允许求交操作，构造该角的两条三等分射线。

首版覆盖全部锐角。直角、钝角及边界情形可在完成首版后继续整理。

### 核心路线

用尺规取得 c=cosθ。由余弦三倍角公式，令 x=cos(θ/3)，有

```math
4x^3-3x=c.
```

于是作直线

```math
y=\frac34x+\frac14c,
```

与给定的 y=x³ 求交。锐角条件下，目标根唯一属于

```math
\frac{\sqrt3}{2}<x<1.
```

将该横坐标转回单位圆，取得 θ/3，再得到第二条三等分射线，并转回原给定角的位置。

### 研究重点

- 把系数构造、投影、取根和角的转移写成实际可执行的步骤。
- 证明目标根的存在性、唯一性与选择规则。
- 明确给定坐标轴、单位长度、整条立方曲线各自提供的信息。
- 区分给定曲线的求交与普通直线、圆之间的求交。

固定三次曲线辅助三等分角已有文献先例。本项目可记录个人独立设问、具体实现、严格证明与可能的程序改进；文献首创性另行核对。

### 首轮完成标准

- [ ] 明确工具和曲线求交规则。
- [ ] 完成全部锐角的构造与正确性证明。
- [ ] 精确核验三次方程、所选根与最终两个三等分角。
- [ ] 用图解释给定曲线在构造中的具体作用。

可以先记录“画线画圆次数”和“立方曲线求交次数”两项成本，不必立即寻找全局最少步骤。

## 六、第 7 项：四个边上点恢复正方形

**建议仓库名：`euclid-square-reconstruction`**

### 题面

给定四点，已知它们分别位于某个正方形的四条边上，恢复符合条件的正方形。

首先整理题集原题中有解、按边的循环顺序给定四点的版本。再决定是否扩展到未给定对应关系的输入。

实际边段与边所在直线是不同约束；是否允许给定点落在正方形顶点上，也应在题面中明确。

### 可用起点

题集中已有“十字架”思路：利用相对两边上的点与 90° 旋转关系，取得另一条边的方向，再恢复其余边。可以将它展开成精确基线，并与文献中的其他构造比较。

### 研究重点

- 证明构造为什么得到正方形，并检查给定点确实落在要求的边段上。
- 区分“构造一个解”与“构造全部解”。
- 分析不同点与边对应关系的重复、遗漏及解的去重。
- 研究辅助点重合、方向未能唯一确定等情形。
- 在扩展输入域中讨论无解、有限解及无穷多解。

### 首轮完成标准

- [ ] 固定点与边的对应关系及边段约束。
- [ ] 将已有作法整理成一条可执行构造并证明。
- [ ] 完成所选输入域中的特殊情形处理。
- [ ] 给出精确案例，说明解的数量与合法性。

本项目以刚性图形重建和解集分类为核心。作图优化可以作为后续工作。

## 七、第 8 项：费马—托里拆利点

**建议仓库名：`euclid-fermat-point`**

### 题面

给定不共线三点 A、B、C，构造使 PA+PB+PC 在整个平面上取得最小值的点 P。

### 经典结论与构造起点

- 三角形的三个内角均小于 120° 时，最优点位于内部，三组夹角均为 120°。
- 某个内角至少为 120° 时，最优点是该角的顶点。
- 经典构造可通过外作等边三角形与相关连线或圆来实现。

可以比较不同构造路线，但首先要明确所求的是距离和的最小点，并完成整个输入域的证明。

### 两种“最优性”分别记录

1. 几何最优性：证明所构造的 P 使距离和最小。这是本题的必要部分。
2. 作图最小性：证明没有更少动作的程序。这是可选研究。

### 分情况讨论重点

三个角均小于 120°、某角恰为 120°、某角大于 120°；等边及等腰等对称输入也应验证。首版保持三点不共线的题面。

### 首轮完成标准

- [ ] 给出正确的分支条件和构造。
- [ ] 证明距离和在全平面上最小，并整理唯一性。
- [ ] 提供精确核验和反映极值性质的图示。

来源：[The Fermat-Torricelli Problem Revisited](https://link.springer.com/article/10.1007/s00591-025-00402-y)。

## 八、第 9 项：均匀四边形薄板的质心

**建议仓库名：`euclid-quadrilateral-centroid`**

### 题面

给定按边界顺序排列的凸四边形 ABCD，构造由其内部及边界组成的均匀薄板的质心。

目标采用面积加权的薄板质心定义；四个顶点的等权平均只是可用的辅助点。

### 一条值得利用的关系

记 E 为两条对角线的交点，V 为四个顶点的等权平均点，G 为薄板质心，则有仿射关系

```math
V=\frac{A+B+C+D}{4},\qquad
G=\frac{4V-E}{3}=\frac{A+B+C+D-E}{3}.
```

等价地，向量 VG 等于向量 EV 的三分之一。这个关系可从三角形的面积加权质心推导，也能和文献构造对照。

### 研究重点

- 严格证明面积加权关系。
- 审计题集已有的辅助圆、对角线中点与交线作法。
- 比较不同路线需要的中间对象。
- 覆盖平行四边形、对角线被平分、辅助圆半径退化等情况。

非凸四边形及更一般多边形暂作扩展，不影响首版完成。

### 首轮完成标准

- [ ] 证明薄板质心公式。
- [ ] 完成全部凸四边形输入的有限构造与分支说明。
- [ ] 用精确面积或积分表达式独立核验目标。
- [ ] 用图展示薄板质心与顶点平均点的关系。

## 九、第 10 项：等积化方

**建议仓库名：`euclid-quadrature`**

### 题面

给定任意非退化三角形，构造与它面积相等的正方形。

首版以三角形为固定输入类型。完成后可考虑凸四边形或一般凸多边形，仍归入同一个项目。

### 核心内容

若三角形的一条底边长为 b，对应高为 h，目标正方形的边长 s 满足

```math
s^2=\frac{bh}{2}.
```

经典路线通过等积变换和比例中项构造实现。应把所需中点、垂线、长度转移及最后的正方形构造写清楚。

### 研究重点

- 区分“取得边长”与“完成正方形四个顶点、四条边”。
- 说明正方形的位置由程序怎样确定；如指定位置或方向，另行列明约束。
- 统一处理锐角、直角、钝角三角形，包括垂足落在边的延长线上的情形。
- 以面积恒等式证明正确性，比较多种等积变换路线。

### 首轮完成标准

- [ ] 完成任意非退化三角形的等积化方。
- [ ] 证明面积精确相等。
- [ ] 提供独立精确核验与逐步图示。
- [ ] 再决定是否推广至其他多边形。

## 十、共同研究方式

### 1. 先固定题目，再研究路线

每个项目先完成一份 `docs/DESIGN.md`，说明：

- 给定什么，哪些对象免费。
- 允许作什么，给定曲线提供哪些求交或取点能力。
- 最终输出是点、直线、完整图形还是类别。
- 输入域、有解域、目标是否唯一，以及特殊输入的范围。

尤其保留第 5、6 项各自的工具模型。给定未知弧的判别能力与给定立方曲线的求交能力，需要分别描述。

### 2. 给成果留出多种形式

以下内容都可以成为主要成果：

- 更短或更清楚的构造。
- 一个完整的有限判定方法。
- 存在性、唯一性或解数分类。
- 一般参数下的正确性证明。
- 对特殊情况和退化分支的完整处理。
- 对已有作法的订正，以及独立精确核验。

经典题目已有作法时，记录文献基线，再明确本项目新增了什么。

### 3. 证据分别记录

原始问答用于提供题目与思路线索。固定实例重放用于核对程序；一般参数证明解释为什么普遍成立；分支覆盖证明说明特殊情形没有遗漏。

如果进一步研究最少步骤，再单独记录搜索范围、构造上界、目前已知记录和严格下界。有限搜索未找到改进，只说明已检查的范围。

### 4. 展示服从研究进度

优先完成题面、构造、证明和核验，再制作展示。静态图、逐步网页和 Manim 动画按需要选择。动画可以作为入口，GitHub 保存完整推导、分支说明与复现材料。
