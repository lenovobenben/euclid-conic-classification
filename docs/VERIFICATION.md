# SageMath 精确核验

## 1. 环境与入口

采用 SageMath 10.7。所有正式相等、零值、正负及矩阵秩的判断使用 $\mathbb Q$、多项式环和实代数数域 `AA`。

入口为 [experiments/verify.py](../experiments/verify.py)。主判定器 [conic_classifier.py](../experiments/conic_classifier.py) 只接收五个点。

## 3. 符号层

多项式环验证的主要关系包括

$$r_1\cdot(r_1\times r_2)=0,\qquad
r_2\cdot(r_1\times r_2)=0,$$

$$\Delta(M^TQM)=(\det M)^2\Delta(Q),$$

$$\Delta(\lambda Q)=\lambda^2\Delta(Q).$$

五点插值部分为每个点构造“其余四点的两对连线方程之积”，检查它在其余四点为零、在一般参数的本点处为非零多项式。具体输入下该非零性由无三点共线保证。

这些检查核对一般代数关系。几何前提与秩的推理完整写于 [PROOF.md](PROOF.md)。

## 4. 独立恢复层

对五个原始点建立评价矩阵

$$\begin{pmatrix}
X_1^2&X_1Y_1&Y_1^2&X_1&Y_1&1\\
\vdots&\vdots&\vdots&\vdots&\vdots&\vdots\\
X_5^2&X_5Y_5&Y_5^2&X_5&Y_5&1
\end{pmatrix}.$$

SageMath 直接求其一维右零空间，恢复完整六系数方程。这条核验路径使用原始坐标，不调用主算法的斜标架叉积公式。

随后逐项核对以下关系。

1. 五个点都精确位于案例的原始曲线上。
2. 独立恢复的方程与案例原始方程成非零比例。
3. 主算法构造的方程与独立方程的标架变换成非零比例。
4. 两种判别量满足精确的正平方比例恒等式。
5. 两种判别量的符号与案例类别一致。

## 5. 几何实施层

[geometry_macros.py](../experiments/geometry_macros.py) 用另一套精确二维直线求交核对尺规宏。

它实际重建 $D,E$ 在两个斜轴上的平行投影，把第二轴上的比例通过 $C_0B$ 的平行线转到 $AB$，随后用独立的加法、减法、乘法平行线构造重算所有辅助量。

最终比较标架坐标、两行辅助量、三个系数和 $\Delta$。这层检查覆盖从几何长度表示到判别量的执行链。

宏自身的任意实操作数正确性在 [CONSTRUCTION.md](CONSTRUCTION.md) 中证明。

## 6. 报告中的数值表示

有理数保存为分数字符串。非有理实代数数保存为最小多项式与隔离该实根的有理区间。生成器会确认区间内恰有一个该多项式的实根。

显示坐标在所有精确检查通过后才转换为浮点数。Manim 读取这些显示数据以及精确判别结果，屏幕曲线的采样和近似位置只负责呈现。

## 7. 失败语义与再生成

任何一项核验失败都会引发异常并以非零状态退出。核验使用显式条件检查，Python 的优化模式也会保留这些检查。

默认命令只输出报告。增加 `--write` 后，在全部检查通过后写入验证报告与动画几何文件，各文件通过临时文件替换，避免留下截断的 JSON。

完整命令见 [REPRODUCING.md](REPRODUCING.md)。
