# SageMath 精确核验

## 1. 两条独立核验路线

几何主解由 [geometric_classifier.py](../experiments/geometric_classifier.py) 重放。它接收四个按弧次序排列的点，以及可见弧的直线求交接口，按实际作图取得中点、平行弦、直径、中心与切线，再判断侧别。

代数核验由 [conic_classifier.py](../experiments/conic_classifier.py) 对五点恢复二次项并判别曲线类别。另以 $5\times6$ 评价矩阵零空间独立恢复完整方程。两套结果和案例真值相互比较。

正式环境为 SageMath 10.7，使用有理数、多项式环与精确实代数数域 `AA`。

## 3. 几何层核验什么

对每条实际构造的平行线，求出与原始曲线的精确交点，再根据原始弧的参数区间筛选。只有位于可见弧上的点才返回主程序。曲线方程仅属于这个输入对象的求交实现，主判定器通过接口取得点。

这项接口模拟题面给定弧所提供的求交能力。主判定器的后续操作均为点线构造，读取的输入中没有曲线类别或方程系数。

核验随后独立检查弦交点在原曲线上、两条直径关系正确、中心满足原始方程的中心条件。所作切线与原始齐次曲线矩阵在切点的梯度直线比较。

## 4. 一般几何恒等式

符号多项式检查包括平行弦中点方程、切点的切线关联、同支双曲线的侧别平方关系，以及齐次退化帕斯卡恒等式。

帕斯卡检查使用五个一般齐次参数点

$$P_i=(u_i^2,u_iv_i,v_i^2).$$

检查三组对边交点的行列式恒为零，并以重复点处的切线代替对应边。这是一条齐次多项式恒等式，覆盖平行分支所对应的无穷远交点。有限尺规分支的可执行性另在 [PROOF.md](PROOF.md) 中逐项证明。

## 5. 代数层与算术附录

五点插值、判别量的不变性和独立方程恢复继续保留，用于交叉检查曲线类型。详见 [ALGEBRA.md](ALGEBRA.md)。

原有有向长度算术重放保存在 [geometry_macros.py](../experiments/geometry_macros.py)，作为算术可构造性附录的核验。其说明为 [ARITHMETIC.md](ARITHMETIC.md)。

## 6. 动画数据

全部核验通过后才导出实际作图中的点线、切线分支和最终类别。动画数据只含图形对象及类别，显示坐标采用浮点投影，正式判定仍来自精确重放。

三个案例的全部 723 个弧采样点也逐点检查原始曲线方程。报告保存数据 SHA-256，Manim 加载时核对。视频只在开头一页简述原理，后续展示作图。

## 7. 报告、失败与复现

任何正式检查失败都会引发异常，程序以非零状态退出。默认打印报告，增加 `--write` 后保存报告和动画数据。各 JSON 文件用临时文件替换，避免截断写入。

精确有理数采用分数字符串，非有理代数数采用最小多项式与唯一实根隔离区间。全部输入域的覆盖性由一般证明保证。命令见 [REPRODUCING.md](REPRODUCING.md)。

## 8. 动画动作与屏幕几何检查

另设四组动画回归测试，直接检查影片所用切线构造的父直线出现顺序、全部五类切线分支，以及多种显示比例下的点线关联。第四组检查两个中心型案例中 $U,Q$ 的圆点分离、标签归属和局部放大图的点线关联。测试调用实际动画方法，具体命令及与文档的步骤对应见 [动画说明第 6 节](../animations/classification/README.md)。

本次审查在“两对辅助线均平行”的动画备用分支中复现了引用 $CU$ 之前漏画该线的问题，修正后全部动画回归测试通过。当前影片的两个中心型案例均走第一对辅助线平行分支。影片中的椭圆案例还明确提示已有中点 $M_2$ 与中心 $O$ 为同一点。
